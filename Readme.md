# 🏡 Velora Estates

A modern luxury real estate website developed with **HTML, CSS, JavaScript, and Bootstrap**.

This project was created as part of a web development challenge and enhanced with a premium design, responsive layout, and dynamic property rendering.

---

## ✨ Features

- 🏠 Luxury property listings
- 💰 Properties for sale and rent
- 📱 Responsive design
- ⭐ Dynamic cards using JavaScript
- 🐶 Pet-friendly indicator
- 🚭 Smoking indicator
- 🔍 Property search
- ❤️ Save favorite properties
- 🌙 Dark mode
- 🎨 Modern and elegant interface

---

## 🛠 Technologies

- HTML5
- CSS3
- JavaScript (ES6)
- Bootstrap 5
